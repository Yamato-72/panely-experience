再現範囲と、実機照合の状況

基準：PANELY 0.70a-usb / versionCode 109。2026年10月15日作成。

この試作は実機の全機能を完全再現した完成版ではありません。ソースに基づく操作フローを実装し、ブラウザで体験できる状態にしたものです。実機との画面・動作照合は未実施です。

範囲試作の状態照合元
初回の挨拶・表示用途選択文言・3分岐を実装。画面寸法と改行はブラウザ向け調整。SetupWizardActivity / WelcomeLayout
USB・アクセス許可・再確認・診断疑似USBで再現。フォルダなし・素材なし・読込失敗を体験条件から切替可能。コピー時間やOS通知は未再現。SetupWizardActivity / UsbImporter
素材の選択・追加・順序・削除・表示時間サンプル素材で実装。削除後も素材ライブラリに残る。画像時間は5/10/15/30秒・ずっと。ManageActivity
再生・タッチ切替・無操作復帰実装。動画は12秒のCSSアニメーション、HTMLは固定の施設案内。実ファイル・動画デコーダー・WebViewの再現は未対応。PlaybackController / ViewerActivity
URL登録と再生切替のみ実装。外部サイトの描画・ログイン・ネットワーク障害は未再現。ManageActivity / ContentRenderer
リモコン・PIN方向移動・決定・戻る・入力切替を実装。左上2秒長押しでPIN、戻るはPINなし。フォーカス移動はブラウザ独自。PanelyReturn / RemoteInputKey
複数プレイリスト作成・選択・名前変更・コピー・削除。最後の1件と時間割使用中リストの削除を防止。PlaylistLibraryActivity / PlaylistCatalog
毎日の時間割開始時刻・翌日への連続再生・ON/OFF・手動表示による停止・復帰を実装。時刻入力はHTML標準入力で、実機の＋/−入力UIとは異なる。欠損ファイルへの退避は未再現。ScheduleActivity / DailySchedule / ScheduleRuntime
HDMI接続・切断・入力切替・戻りを疑似再現。実映像、カメラ権限、入力競合、信号検出エラーは未再現。HdmiInActivity
外部アプリ固定サンプルの追加確認・起動・戻り。実機のインストーラー画面と各アプリの動作は未再現。SetupWizardActivity / ExternalAppHostActivity
操作音・焼き付き防止・PIN変更・初期化設定保存・再起動体験に反映。取込完了音は元ソースの音源、全操作の音・モーションは未再現。ManageActivity / Sfx / ViewerActivity
管理画面の待機時計60秒無操作で表示、操作で復帰。ManageActivity
電源・ホーム運用電源ON/OFFと保存した設定での再開を疑似再現。起動時の白色androidロゴは提供された実機写真を参考に再現（約3秒）。OS起動・ホーム選択・自動復旧・実機の起動時間は未再現。BootReceiver / StartupLaunchGuard（実機確認が必要）
Android / ToolBox / 保守画面Wi-Fiは仮画面。他のOS・メーカー設定と隠し保守メニューは未再現。対象機種の資料・実機が必要

完全再現に向けて必要な確認

  1. 対象ディスプレイの型番、縦横、タッチ対応、リモコン、端子位置。
  2. 0.70aを搭載した実機の初回起動と設定済み起動の画面。
  3. 各画面・ダイアログ・異常系をこの試作と並べて照合。
  4. Android設定・ToolBox・外部アプリの範囲を確定し、画面と操作を追加。
  5. 社内検証後に、導入前のお客様向け公開版として表示を確定。

Androidソース本体、社内資料、保守用コードは公開用フォルダへ同梱していません。
